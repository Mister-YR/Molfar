# Мольфар

**Мольфар** — маленький моніторинг домашньої чи офісної мережі. Його ставлять на мініком'ютер
(наприклад, Orange Pi Zero 3) або у віртуальну машину, і він цілодобово стежить за інтернетом:
чи він є, наскільки швидкий і стабільний. Усе видно у веб-інтерфейсі з телефона чи комп'ютера,
а про проблеми Мольфар сам повідомляє в Telegram.

## Навіщо

Провайдер обіцяє 100 Мбіт/с, а відео гальмує? Інтернет «іноді зникає», але коли саме — невідомо?
Мольфар відповідає на такі питання цифрами:

- **Швидкість** — щоночі, або за розкладом робить серію speedtest і рахує середню швидкість завантаження й віддачі.
- **Пінг і джитер** — постійно пінгує `1.1.1.1`, `8.8.8.8` та ваші адреси: затримка, втрати пакетів, стабільність.
- **Історія** — графіки за добу, тиждень, місяць і рік, експорт у CSV (зручно показати провайдеру).
- **Сповіщення** — у Telegram, коли зв'язок пропав і коли повернувся.
- **Провайдер** — хто зараз дає інтернет і чи змінилась зовнішня IP-адреса.
- **Мапа мережі** — які пристрої є у вашій мережі та коли з'являються нові.
- **WireGuard** — керування VPN-тунелями, щоб заходити в Мольфар (і в домашню мережу) звідусіль.

Мольфар написаний на Python, дані зберігає в одному файлі SQLite, інтерфейс доступний українською та англійською.

## Що в репозиторії

| Тека | Що це | Кому підійде |
|---|---|---|
| [`basic-version/`](basic-version/) | **Базова версія**: speedtest, пінг, історія, Telegram, провайдер, мапа мережі, WireGuard. Найлегша, мінімум залежностей. | Тим, кому потрібен просто контроль якості інтернету. |
| [`advanced-version/`](advanced-version/) | **Розширена версія** — усе з базової, плюс **Інциденти** (облік збоїв: зникнення інтернету, перезавантаження, недоступність роутера), **Wi-Fi ефір** (сусідні мережі, завантаженість каналів, порада, який канал обрати, позначки DFS) і опитування роутерів **TP-Link / ASUS** (Поки не протестовано). | Тим, хто хоче бачити більше, ніж «є інтернет чи нема», і налаштовувати Wi-Fi. |
| [`advanced-version_docker/`](advanced-version_docker/) | **Розширена версія в Docker**: той самий код, плюс `Dockerfile` і `docker-compose.yml` для запуску на віртуальній машині чи сервері **x86_64 або ARM64**. | Тим, хто хоче запустити Мольфар не на Orange Pi, а на ВМ, NUC, NAS чи сервері. |

У кожній теці є:

- `molfar/` — сам проєкт, готовий до встановлення:
  - `molfar/molfar/` — серверна частина (Python, FastAPI): перевірки, розклад, база, сповіщення;
  - `molfar/static/` — веб-інтерфейс (HTML, CSS, JavaScript, графіки Chart.js);
  - `molfar/deploy/` — системні файли: сервіс systemd, помічники для WireGuard і Wi-Fi, приклад профілю VPN;
  - `molfar/tests/` — автоматичні тести;
  - `molfar/install.sh` — встановлення одною командою.
- `README.md` / `README.en.md` — повний опис версії (українською / англійською).
- `molfar.zip` — та сама версія одним архівом, щоб зручно скопіювати на пристрій (у Docker-теці архіву немає).

## Як почати

**На Orange Pi або іншому мініком'ютері з Debian / Ubuntu / Armbian:**

```bash
cd advanced-version/molfar      # або basic-vesrion/molfar
sudo ./install.sh
```

**На віртуальній машині чи сервері з Docker:**

```bash
cd advanced-version_docker/molfar
cp .env.example .env            # пароль, порт, часовий пояс
docker compose up -d --build
```

Потім відкрийте в браузері `http://<IP-пристрою>:8080` (логін `admin`, пароль `Molfar` — змініть його
в налаштуваннях). Подробиці — у README відповідної версії та в
[`DOCKER.md`](advanced-version_docker/molfar/DOCKER.md) для Docker.
